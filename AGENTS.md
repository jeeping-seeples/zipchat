# Agent instructions

1. Read `README.md`, `PLAN.md`, `DECISIONS.md`, `PROGRESS.md`, `BLOCKERS.md`, and `docs/` before work.
2. Begin with the read-only audit in `docs/JULES_FIRST_TASK.md`.
3. Do not invent gateway endpoints, JSON fields, streaming formats, or authentication behavior. Read the gateway's approved API contract.
4. Keep provider SDKs and provider credentials out of this repository.
5. Make small, reviewable changes and report files changed, commands run, test outcomes, and blockers.
6. Ask before adding dependencies, changing UI frameworks, changing persisted conversation formats, or introducing telemetry.
7. Never commit credentials or `.env` files.
8. Pause for human approval after each task.
